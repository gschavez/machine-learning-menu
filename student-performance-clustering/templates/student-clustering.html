Student Performance Clustering

This application uses the K-Means clustering algorithm to identify groups of students according to their mathematics, reading, and writing performance.

1. Dataset and Justification

The dataset contains information about students' academic performance in mathematics, reading, and writing. It contains 1,000 student records and provides three numerical variables that can be used to identify groups of students with similar academic performance.

This dataset was selected because student performance is directly related to the team's topic and provides suitable numerical variables for applying K-Means clustering.

3. Data Preprocessing

Before training the clustering model, the dataset was inspected to identify missing values, duplicated records, data types, and the numerical variables required by the algorithm.

  • No missing values were found.
  • No duplicated records were found.
  • The three selected variables are numerical.
  • The selected features were extracted from the original dataset.
  • StandardScaler was applied before K-Means.

Standardization was applied because K-Means uses distances to determine cluster membership. Scaling the variables places them on a comparable standardized scale before calculating distances.

4. K-Means Configuration

The model was implemented using Scikit-learn's KMeans algorithm. Different values of K were compared using inertia and silhouette analysis. K = 2 was selected for the final model because it produced the highest silhouette value among the evaluated options and provided an interpretable grouping of the students.

n_clusters = 2
init = "k-means++"
n_init = 10
random_state = 42

The K-Means++ initialization strategy was used to obtain suitable initial centroids. Ten initializations were evaluated by the algorithm, and a fixed random state was used to make the results reproducible.
