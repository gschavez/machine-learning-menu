Decision Tree Application

Classifying the outcome of a tennis match using a Decision Tree trained on real ATP match data.

Problem Context

This application uses a Decision Tree to classify the outcome of a tennis match between two players, Player A and Player B. Unlike the Logistic Regression model (which uses a single variable), this model uses four independent variables describing both players.

The model attempts to classify each match into one of two classes: Player A wins the match, or Player A loses the match.

Independent Variables (X)

  • player_a_ranking — Player A's ATP ranking.
  • player_b_ranking — Player B's ATP ranking.
  • player_a_recent_win_rate — Player A's win rate over their last 10 matches.
  • player_b_recent_win_rate — Player B's win rate over their last 10 matches.

Target Variable (Y)

player_a_wins — binary result of the match.

0 = Player A loses 1 = Player A wins

The dataset is loaded from data/tennis_matches.csv using Pandas, built from real ATP match results (2021–2024). It is split into 80% training data and 20% testing data using train_test_split, with stratification on the target class.

The DecisionTreeClassifier from scikit-learn is trained on the training set. Predictions shown below and on the Evaluation page are generated by the trained model — none of the results are hard-coded.
