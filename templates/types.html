Types of Machine Learning

Machine Learning can be divided into different types depending on how a system learns from data.

🎯 Supervised Learning

What is it?

The model learns from labeled data where the correct answer is already known.

Characteristics
  • Uses labeled data.
  • Learns from examples.
  • Makes predictions.
Type of Problems
  • Classification
  • Regression
Example:

Predicting house prices using size and location.

🔍 Unsupervised Learning

What is it?

The model works with unlabeled data and discovers patterns or groups.

Characteristics
  • Uses unlabeled data.
  • Finds hidden patterns.
  • Groups similar information.
Type of Problems
  • Clustering
  • Dimensionality Reduction
  • Pattern discovery
Example:

Grouping customers according to their shopping habits.

🤖 Reinforcement Learning

What is it?

An agent learns by interacting with an environment and receiving rewards or penalties.

Characteristics
  • Learns through experience.
  • Uses rewards and penalties.
  • Improves decisions.
Type of Problems
  • Decision making
  • Control Problems
  • Sequential actions
Example:

A robot learning how to reach a destination.
