Decision Tree

Concepts behind Decision Trees, the classification algorithm assigned to this group, applied here to predict the outcome of a tennis match.

What is a Decision Tree?

A Decision Tree is a supervised learning algorithm that classifies data by asking a sequence of yes/no questions about the input variables. Each internal node represents a question about one feature (for example, player_b_ranking <= 20.5), each branch represents the answer to that question, and each leaf node represents a final predicted class.

Starting from the root node, an observation travels down the tree, answering one question at a time, until it reaches a leaf. The class assigned to that leaf becomes the model's prediction.

How the algorithm works

During training, the algorithm looks at every feature and every possible split point, and picks the split that best separates the classes. "Best" is measured using an impurity metric, most commonly the Gini index or entropy / information gain. A pure node (one where all samples belong to the same class) has an impurity of 0.

  1. Start with all training samples at the root node.
  2. Evaluate every feature and threshold to find the split that most reduces impurity.
  3. Divide the samples into two child nodes using that split.
  4. Repeat the process recursively on each child node.
  5. Stop when a node is pure, has too few samples to split, or a maximum depth is reached, turning it into a leaf with a predicted class.

Types of problems it can solve

Decision Trees are versatile and can be used for:

Binary classification Multi-class classification Regression (predicting numbers) Feature importance analysis

In this project, the tree is used for binary classification: predicting whether Player A wins (1) or loses (0) a tennis match.

Main characteristics

  • Works with both numerical and categorical variables without requiring feature scaling.
  • The learned structure is a set of simple, human readable if/else rules.
  • Can naturally handle non-linear relationships between variables that models like Logistic Regression cannot capture directly.
  • Splits are made one feature at a time, so the model implicitly ranks which variables are most useful for classification.

Advantages

  • Easy to interpret and visualize.
  • No need to scale or normalize the data.
  • Captures non-linear relationships between variables.
  • Handles both numerical and categorical features.

Limitations

  • Prone to overfitting, especially with deep, unrestricted trees.
  • Small changes in the training data can produce a very different tree (instability).
  • A single tree usually generalizes worse than ensemble methods such as Random Forest.
  • Splits are made one variable at a time, which can miss combined effects between variables.

Real-world example

Banks commonly use Decision Trees to decide whether to approve a loan application. The tree asks questions such as "Is annual income above a threshold?" or "Is the credit history length above a threshold?", and routes the applicant down the tree until it reaches a leaf labeled Approve or Reject. This project applies the same idea to sports data: instead of approving a loan, the tree decides whether Player A is predicted to win or lose a tennis match.
