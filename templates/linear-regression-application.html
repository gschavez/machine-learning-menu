Linear Regression: Application

Predicting taxi fare based on trip distance

Problem Context

This application estimates the cost of a taxi ride based on the distance traveled. The phenomenon analyzed is the relationship between trip distance and fare price. The purpose of applying Linear Regression here is to predict the fare a passenger would pay for a given distance, based on historical trip data.

Independent Variable (X)

Distance (km) — the input used to make the prediction.

Dependent Variable (Y)

Cost ($) — the value the model attempts to predict.
