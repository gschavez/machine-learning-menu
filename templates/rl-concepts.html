REINFORCEMENT LEARNING

Reinforcement Learning: Concepts

The ideas you need to understand the exercise: a virtual robot that learns, by trial and error, how to cross a 10 × 10 maze and reach the target.

What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of machine learning where an agent learns to make decisions by interacting with an environment. Nobody gives it the right answer. Instead, after each action it receives a reward or a penalty, and it slowly learns which actions lead to better results.

The goal is to learn a policy: a way of choosing actions that maximizes the total reward the agent expects to get. In our exercise, the robot is not told the route. It discovers it by trying, failing and improving.

Compared with other types: supervised learning learns from labeled examples, unsupervised learning looks for groups in unlabeled data, and RL learns from rewards obtained by acting.

The agent–environment cycle

Agent

The virtual robot. Chooses one action: Up, Down, Left or Right.

Environment

The 10 × 10 maze and its rules. Decides what happens after each action.

Agent → action → Environment → new state + reward → Agent

This loop repeats again and again. With each turn, the agent has a new experience to learn from.

Key concepts, one by one

The policy is the rule that tells the agent which action to take in each state.
Example: in cell (0,0) the best action may be Right; in (0,1) it may be Down. The full set of those choices is the policy the robot learns.

  • Step: one action and its result. The robot moves once.
  • Episode: a full attempt, from the start A until the robot reaches T or runs out of allowed steps.
  • Experience: what is learned from one step: (state, action, reward, next state).

The immediate reward is what the robot gets right after one action. The return is the sum of all the rewards it will get from now on, with future rewards counting a bit less.
G = r1 + γ·r2 + γ²·r3 + ...
A move that gives -1 now but leads toward the target can be better than a move that gives 0 now but leads into a danger zone.

A number between 0 and 1 that says how much the agent cares about future rewards. Close to 0, the robot only thinks about the next step. Close to 1, it plans for the long run.
The class exercise used γ = 0.95, so the reward at the target still matters even from far away.

  • V(s): how good it is to be in a state, assuming the agent keeps following its policy.
  • Q(s,a): how good it is to take action a while in state s.
V(s) = maxa Q(s,a)
For each cell, the Application page shows four Q-values: Up, Down, Left and Right. The agent picks the action with the highest one.

Q-Learning is the algorithm used in this exercise. After each step, the agent corrects its estimate of Q(s,a) using what it just observed:
Q(s,a) ← r + γ · maxa' Q(s',a')

Here r is the reward and s' is the next state. In the class exercise, Q(s,a) is estimated with an SGDRegressor: predict() gives the Q-values and partial_fit() updates the model with every new transition.

Exploration

The robot chooses a random action to discover the maze. It may bump into a wall, but it finds out things it did not know yet.

Exploitation

The robot chooses the action with the best Q-value it knows so far. It uses what it has already learned.

Epsilon-Greedy strategy

To balance both ideas, the agent uses a number ε (epsilon). At each step:

  • With probability ε it explores (random action).
  • With probability 1 − ε it exploits (best Q-value).

Training starts with ε high (the class exercise used 1.0) so the robot explores a lot, and ε decreases little by little until it reaches a minimum. This is the epsilon decay.

initial ε minimum ε ε decay γ training episodes
Too little exploration and the robot may settle for a bad route. Too much and it never uses what it learned.
