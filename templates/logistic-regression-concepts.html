Logistic Regression: Concepts

Understanding how a classification model estimates the probability of a binary outcome

What is Logistic Regression?

Logistic Regression is a supervised Machine Learning algorithm used for classification problems . Instead of predicting a continuous numeric value, it estimates the probability that an observation belongs to one of two possible classes. A threshold is then used to convert that probability into a class prediction.

The Logistic Function

P(Y = 1) = 1 / (1 + e-z)
P(Y = 1) — probability of class 1 z — weighted combination of the input variables e — mathematical constant used by the logistic function

How does it work?

01
Input Data

The model receives numerical features that describe each observation.

02
Probability

The logistic function converts the model output into a probability between 0 and 1.

03
Classification

A threshold is used to assign the observation to class 0 or class 1.

Key Concepts

Probability

The model estimates how likely an observation is to belong to class 1.

Decision Threshold

A threshold converts the predicted probability into a binary class.

Binary Output

The final prediction is represented as either class 0 or class 1.

Classification

Logistic Regression is commonly used when the target has two possible outcomes.

Tennis Match Prediction

In this project, Logistic Regression is used to predict the winner of a tennis match. The model uses the difference between the players' rankings as its input variable.

Ranking Difference Player A Wins = 1 Player A Loses = 0

A positive or negative ranking difference provides information about the relative ranking of the players. The trained model uses this information to estimate the probability that Player A wins.

Model in This Project

The model was trained using a tennis dataset containing 1,200 matches. The data was divided into training and testing sets using an 80/20 split.
