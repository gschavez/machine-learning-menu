Dataset and Variables

The dataset contains student performance information in Mathematics, Reading, and Writing. These variables were selected because they represent numerical measures that can be used to identify groups with similar academic performance.

Unlike supervised learning, no predefined target class is used. The clusters are generated from the similarities between the selected numerical variables.

Measure of cluster separation

The Silhouette Score compares how similar each observation is to its assigned cluster with its similarity to other clusters.

Values closer to 1 indicate stronger separation, values around 0 indicate observations near cluster boundaries, and negative values may indicate possible inappropriate assignments.
