Use Case 1: Netflix — Content Recommendation System

Context: Netflix needs to recommend content that is likely to interest each user in order to increase engagement and maintain subscriptions.

Data used: Viewing history, ratings, watch time, pauses, time of day, and device information.

What the model predicts/discovers: The system identifies patterns in user behavior and recommends titles that are likely to match each user's interests and preferences.

Type of Machine Learning: Unsupervised Learning, because the system can identify patterns and similarities in user preferences from large amounts of behavioral data without relying exclusively on manually defined rules.

Benefit: Improves content discovery, increases user engagement, and can help reduce subscription cancellations.
