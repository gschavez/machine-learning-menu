Logistic Regression: Application

Classifying whether Player A wins a tennis match based on the ranking difference between the players.

Problem Context

This application uses Logistic Regression to classify the outcome of a tennis match. The model analyzes the ranking difference between Player A and Player B and predicts whether Player A wins or loses the match.

Independent Variable (X)

ranking_difference — the difference between Player B's ranking and Player A's ranking.

Target Variable (Y)

player_a_wins — the binary result that indicates whether Player A wins the match.

0 = Player A loses 1 = Player A wins

Model Training and Testing

The tennis dataset is loaded from a CSV file using Pandas. The data is divided into 80% for training and 20% for testing using train_test_split.

The Logistic Regression model is trained using the training data and then evaluated using the testing data. The predictions are generated by the trained model rather than being manually assigned.
