Use Case: Metro de Barcelona

How Machine Learning can help improve air quality and optimize ventilation inside metro stations.

RESPIRA System

The Barcelona Metro can use intelligent systems to monitor environmental conditions inside its stations and improve the quality of the air for passengers.

The system analyzes information such as temperature, humidity and air quality to help determine when and how ventilation should be adjusted.

How is Machine Learning used?

Data

The system uses environmental information such as temperature, humidity and air quality collected from the stations.

Prediction

Machine Learning analyzes the available data to predict environmental conditions and ventilation needs.

Adjustment

The system can help determine when and how to activate or adjust ventilation.

Benefit

Better air quality can be achieved while reducing unnecessary energy consumption.

Type of Machine Learning

This use case can be associated with Supervised Learning, because the model can learn from historical environmental measurements and their corresponding ventilation conditions.

Supervised Learning Regression Prediction Time Series

Why is it useful?

Applying Machine Learning to environmental monitoring can help transportation systems make better decisions based on real-time and historical data.

In this case, the objective is to maintain suitable air quality for passengers while using ventilation systems more efficiently.
