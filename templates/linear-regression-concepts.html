Linear Regression: Concepts

Understanding how a model learns to predict a numeric value

What is Linear Regression?

Linear Regression is a supervised Machine Learning algorithm used to model the relationship between two variables by fitting a straight line to the observed data. It is one of the simplest and most widely used algorithms for prediction tasks, and it solves regression problems — predicting a continuous numeric value such as a price, a temperature, or the cost of a taxi ride.

The Regression Formula

Y = b0 + b1X
Y — predicted value (dependent variable) X — input value (independent variable) b₀ — intercept (value of Y when X = 0) b₁ — slope (how much Y changes per unit of X)

How does it work?

01
Independent Variable (X)

The known input value used to make the prediction.

02
Trained Model

The regression line, learned from historical data, connects X to Y.

03
Dependent Variable (Y)

The predicted output value the model estimates.

The Two Variables

Independent Variable (X)

The input used to make the prediction. It is the value we already know.

Dependent Variable (Y)

The output the model tries to predict, based on the independent variable.

Linear Relationship

As X increases or decreases, Y tends to change in a consistent, proportional way.

Regression Line

The straight line that best fits the data, minimizing the distance to all data points.

Prediction

Once the model is trained and the regression line is calculated, it can be used to predict the value of Y for a new, previously unseen value of X — simply by locating that point on the line.

A Simple Example

Applying the formula to this project's topic:

X = Distance (km) Y = Cost ($) Model learns b₀ and b₁ from 600 trips

If we know the distance of a taxi ride (X), Linear Regression can predict the approximate cost of that ride (Y), based on patterns learned from hundreds of previous trips.
