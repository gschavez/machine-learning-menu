Linear Regression

Understand how linear regression models the relationship between variables and uses that relationship to make predictions.

What is Linear Regression?

A simple and fundamental supervised learning algorithm.

Definition

Linear Regression is a supervised machine learning algorithm used to model the relationship between a dependent variable and one or more independent variables.

In Simple Linear Regression, the model uses one independent variable to estimate the value of one dependent variable.

The objective is to find the line that best represents the relationship between the observed data points.

Main Objective

The main objective is to use existing data to identify a relationship and then use that relationship to estimate unknown values.

Independent & Dependent Variables

Understanding the role of X and Y is essential.

X

Independent Variable

The variable used as input by the model. Its value is used to estimate the dependent variable.

Distance (km)

In our project, distancia_km represents the distance traveled by a taxi.

Y

Dependent Variable

The variable that the model attempts to predict based on the independent variable.

Cost (COP)

In our project, costo represents the estimated taxi fare.

How Does It Work?

The model learns a relationship from historical data.

1. Data Distance and cost records
2. Training Find the best-fitting line
3. Model Learn the relationship
4. Prediction Estimate a new cost

Regression Equation

Simple Linear Regression can be represented mathematically.

Y = β₀ + β₁X

Y

Predicted dependent variable.

β₀

Intercept of the regression line.

β₁X

Effect of the independent variable on the prediction.

Simple Example

Applying the concept to our taxi dataset.

Predicting Taxi Cost

Imagine that we want to estimate the cost of a taxi trip based on the distance traveled.

If the passenger enters a new distance, such as 10 km, the trained regression model can use the learned relationship between distance and cost to estimate the corresponding fare.

Distance → Regression Model → Estimated Cost

The important idea is that the prediction is generated by the trained model rather than manually assigning a value.
