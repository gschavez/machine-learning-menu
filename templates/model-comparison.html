A note on Linear Regression (taxi fare)

The Linear Regression model predicts a continuous value (taxi fare in dollars), not a class label, so it is evaluated with different metrics (like error in dollars) rather than accuracy/precision/recall. For that reason it isn't included in the table above, which compares classification models only. See the Linear Regression application.
